# Agnes 图像生成

用 **`agnes_image` 工具**访问 `agnes-image-2.5-flash`。密钥在插件配置里用「Agnes 站点」面板填写（中国站 `apiKeyCn` / 国际站 `apiKeyIntl`），无需在对话中暴露。图片会直接下载到本地，工具返回绝对路径。

## 调用方式

文生图：

```
agnes_image(prompt="日出薄雾峡谷上方的发光浮空城市，电影级写实，广角，高视觉密度")
```

指定档位与宽高比：

```
agnes_image(prompt="产品主图，玻璃立方体，白底柔光", size="2K", ratio="16:9")
```

图生图（本地路径或公网 HTTPS URL 均可，本地会自动转 Data URI）：

```
agnes_image(prompt="改成雨夜赛博朋克霓虹，保留原始构图和相机角度", image=[".\\in\\street.png"])
```

多图合成（`image` 按顺序说明每张图的角色）：

```
agnes_image(prompt="第一张图作为主角，第二张图作为产品参考，生成电影级活动海报", image=[".\\a.png", ".\\b.png"])
```

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `prompt` | 必填 | 提示词 |
| `model` | `agnes-image-2.5-flash` | 图像模型 ID；须在**当前站点**的图像模型集内，不可随意填 |
| `size` | `1K` | 档位：`1K` / `2K` / `3K` / `4K` |
| `ratio` | `1:1` | `1:1 3:4 4:3 16:9 9:16 2:3 3:2 21:9` |
| `image` | — | 参考图数组；传入即为图生图，多张为合成 |
| `output_name` | — | 自定义文件名主名（不含扩展名），会清洗为安全字符；不传则用提示词前 16 字符自动短名 |

> **模型白名单**：`model` 只能在配置卡「Agnes 站点」区、Key 框下方的模型下拉
> （**当前站点**的图像模型集）里选；选「自定义…」可输入任意 ID 作为生效项。
> 填了 API Key 可点「校验 Key & 拉取模型」自动从 `/v1/models` 导入当前站模型。
> 默认就是 `agnes-image-2.5-flash`，通常不用传。取集外的 ID 会被拒绝并提示可选值。

> **输出目录**：工具没有 `out_dir` 参数。图片默认写到会话工作目录下的 `out/agnes-images`；
> 操作者可在插件配置的 `outDir` 里改输出根目录。
> **文件名**：传了 `output_name` 就用**纯名**（如 `output_name="cityscape"` → `cityscape.png`，单张直接用它；多张才追加 `_0/_1`），不带时间戳；
> 不传则用 `时间戳_提示词前16字符[_序号].ext`。**每次生成请给不同的 `output_name`**，避免覆盖同目录同名文件。

## 要点

- 不要请求 `1920x1080`、`2560x1440` 这类非原生精确尺寸，会被标准化；要 16:9 就用 `size="2K", ratio="16:9"`。
- 图生图不要传 `tags`；输入图放在 `extra_body.image`（工具已处理）。
- 生成耗时数秒到数十秒，默认超时 300 秒。
- **RPM 限制（重要）**：Agnes 只按 **RPM**（每分钟请求数）限流，没有 RPS 概念；且按**输出档位**区分。免费/默认密钥的「实际 RPM」公开参考值：`1K=20`、`2K=10`、`3K=1`、`4K=1`（Token Plan 为 `1K=100`、`2K=80`，`3K/4K` 同样只有 1）。
- **插件已内置跨进程限流**：每次请求前先到本地滑动窗口配额池排队，多个会话/进程并发时**合计**计数（因为 Agnes 的限制按密钥类型共享，不按单个 key 算，各算各的必然超限）。所以连续批量生图会自动排队等待，无需手动 sleep。状态目录默认 `%TEMP%\agnes-ratelimit`，可用 `AGNES_RATELIMIT_DIR` 改；目录不可写时自动放行不限流。
- **3K / 4K 只有 1 RPM**，即每分钟最多一张，批量任务请用 `1K`/`2K`。
- **重试策略**：遇到 503（生图队列已满）或 429（限流）时自动重试，间隔递增 `3s→8s→15s→25s→40s`，最多 6 次尝试后放弃；网络类错误（超时/连接失败）走同一退避。**429 例外**：改为等待 60 秒（或服务端 `Retry-After`，上限 120 秒），因为 429 说明已到真实上限，用短退避只会继续撞墙。
- 提示词结构：文生图 `[主体]+[场景]+[风格]+[光照]+[构图]+[质量]`；图生图 `[改动]+[新风格/场景]+[增删元素]+[需保留元素]`。

## 交付

工具返回 `files`（本地图片绝对路径）、`urls`（云端直链）、`size`、`ratio`、`mode`。

生成成功后用 `present` 工具把 `files` 里的图片作为交付物呈现给用户，并在回复中说明模型、尺寸、档位和所用提示词。
